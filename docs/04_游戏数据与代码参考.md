## 3. 效果（SpeAddDataBase，215 种）

- 天赋效果写法：`效果名+数值;效果名+数值`。「百分比显示」=1 的效果数值写小数（0.2 = +20%）。
- 触发时机：0 常驻、1 攻击时、2 被攻击时。
- 常用：吸内（攻击时）、斗转（被攻击时）、调息（攻击时）、内劲、好感获取（常驻）、各类「××威力」。
- 原版效果最多的天赋：387「终归一统」，24 个效果（修改器天赋页上限也设为 24）。
- 参考天赋：69 万物归墟（护体真气+0.3;吸内+0.3）、77 扭转乾坤（斗转+0.2;调息+0.2）、388 鸾凤和鸣（好感获取+0.2）、374 登顶泰岳（十五项+2）。

### 「本门武学威力」（效果 213）的判定
代码 `BattleController.CountBaseDamage`：出手者有门派，且**武学数据表（KungFuData）里该武学的「所属势力」== 出手者当前所属门派（belongForceID）**，伤害才乘 (1 + 本门武学威力)。与藏经阁无关，与师承门派（skillForceID）无关。
KungFuData 共 1051 门武学：347 门无门派（-1），其余只分给 0~19 号门派（每派 29~46 门）。**20~29 号小门派（含青城派 28 → 合欢宗）没有本门武学**，这个效果对它们无效。

## 4. 自创武学（2026-11 新增）

入口：城市私宅 → 练功房 → 自创武学（BuildingData 73 号的互动选项 `CustomSkillEntry`）。原版规则（代码确认）：
- 品级 0~5 共 6 档，**每个品级玩家只能自创 1 门**（`WorldData.HavePlayerCustomSkill`）。→ 修改器改为每品级 9 门。
- 最高品级（5）需要主角有天赋 374「登顶泰岳」。
- 需要一门**同品级、满级（10 级）、非自创**的武学作为模板（`PlotController.PlayerHaveCustomSkillTemplate`）。
- 自创武学编号从一个起始值向后找空位，无编号上限；NPC 也会自创（`createByPlayer = false`，不计入玩家数量）。
- 存档：`WorldData.customSkills`（Save 里）。

## 5. 存档结构要点

### 存档格式（游戏 1.1.3 / 2026-11 起变化）
- Hero、Save、Info、TempHero 都改为 **gzip 压缩的 JSON**（头部 `1f 8b 08 00 00000000 00 0a`，无文件名、无时间戳）。游戏仍能读取旧版纯 JSON 存档，读档后再存就变成新格式。
- **值为 null 的字段一律省略**（如地块的 `name` / `building` / `areaRoadData`，门派的 `forceSetName`，人物的 `heroNickName`、天赋的 `sourceHero`）。
- 不再保存的派生字段（读档时重新计算）：Hero 的 totalAttri、totalFightSkill、totalLivingSkill、maxhp、realMaxHp、maxPower、realMaxPower、maxMana、realMaxMana、armor、skillCount、totalAddData、fightScore、forceMission、settingName。
- Save 顶层新增 `customSkills`（自创武学，对象），删除 `PlayerAuctionItem`；Area 删除 speBoxColliderSize（setAreaName 为 null 时省略）。
- `SaveVersion` 为 `1.1.3 f0`。大小：存档 4 的 Hero 20MB JSON → 2.1MB 压缩，Save 9.8MB → 0.8MB。

### Save 文件（JSON 对象）
- `Forces[]`：forceID、forceName、forceSetName（自立后的名字）、replacedForce（是否自立）、mainAreaID、forceMaleRate（男弟子比例）、ownAreasID、ownHeros、techSpeAddData …
  - 自立门户 = 替换一个现有门派（保留其 forceID）。存档 4：合欢宗 = 替换青城派（forceID 28），驻地 mainArea 58。存档 8 是同一周目自立之前。
- `speBuildingUnlocked`：已解锁的特殊建筑编号列表（顶层）。
- `Areas[]`：mapWidth × mapHeight，`areaTiles` 下标 = 行 × 宽 + 列；tileType：-3 城外、-2 城门、-1 城墙、0 可建造（building 为 null = 空地，buildingID -1 = 残垣）、1 道路、2 中心。地面贴图 (行+列) 偶数 Gray、奇数 White。游戏画面高行在上。
- `customSkills`（自创武学）、`worldTime`、`plotHappened` 等。

### Hero 文件（JSON 数组，约 30MB）
- 第 0 个元素 = 主角（heroID 0）。
- heroName（全名）、heroFamilyName（姓）、isFemale、belongForceID（所属门派）、skillForceID（师承门派）。
- `heroTagData`：天赋列表 `{tagID, leftTime:-1.0, sourceHero:null}`。
- 外观：`faceData.faceID`（9 个数）+ `skinColorDark`（肤色）+ `isFemale`。
  游戏「导出/导入」外貌码格式（`HeroData.GenerateFaceCode / LoadFaceCode`）：`性别/9个faceID/肤色`，例 `0/5/83/60/38/41/6/38/-1/-1/0`（0 = 男）。

### Info 文件
`SaveDetail` 首行是主角名，后面是门派与职位（存档列表显示用），改主角名时一起改。

### 其他
- Steam 云存档会在启动游戏时覆盖本地存档（如果云端更新）→ 改存档时关闭云同步或在游戏内读档。
- 自动存档在 10 号槽。
