# 合欢宗修改器 使用说明

程序：`release\合欢宗修改器.exe`（Windows，.NET Framework 4，Win10/11 自带，无需安装）

顶部「游戏目录」填游戏根目录（含 `GameAssembly.dll` 的文件夹），点「检测」。目录会被记住。
下方日志栏记录每一步操作。

---

## 1. 「游戏文件」页

列表里每一行是一个功能，可以单独打勾：

| 功能 | 说明 | 涉及文件 |
|---|---|---|
| 门派特性随特殊建筑 | 驻地有哪派的特殊建筑，主角就拥有那派的门派特性（建筑功能 + 特性规则效果） | GameAssembly.dll |
| 自创武学每品级9门 | 原版每个品级只能自创 1 门 | GameAssembly.dll |
| 秘籍持有数量提示 | 悬停秘籍时多一个框，显示背包 / 仓库里的数量 | GameAssembly.dll |
| 合欢殿 | 新建筑（借用金顶外观），自立门户后可建造 | resources.assets、globalgamemanagers、sharedassets0.assets |
| 合欢宗主天赋 | 新天赋，效果在「合欢宗主天赋」页设置 | resources.assets |

- 打开时默认勾选所有能装的功能（已安装 + 未安装）。取消勾选已安装的功能 = 卸载它。
- 「按勾选安装 / 更新」：按勾选结果写文件，执行前会列出要安装/更新/卸载的功能。勾选与现状一致时按钮为灰色。
- 「全部还原为原版」：所有改过的文件恢复原版。
- 状态：`未安装` / `已安装` / `已安装，可更新`（例如改了天赋效果后）/ `不兼容：原因`（红色，不能勾选，其余功能照常可装）。
- **必须先关闭游戏**（游戏运行时会锁住这些文件）。
- 第一次修改某个文件前，会把原版存为同目录下的 `文件名.bak`。游戏更新后，检测到当前文件是新原版，会自动用新原版覆盖旧备份。

### 卸载时注意
- 卸载「合欢殿」后，存档里已建好的合欢殿会无法正常显示。
- 卸载「合欢宗主天赋」后，已拥有该天赋的角色可能出错。
- 存档里用了这两个东西时，游戏没装补丁就**不要读档**。

---

## 2. 「存档」页

左边列出所有存档槽（名字、门派、职位），点一个槽位，右边显示可做的修改：

| 选项 | 说明 | 条件 |
|---|---|---|
| 解锁合欢殿 | 把合欢殿加入「已解锁特殊建筑」，建造列表里出现 | 已自立门户；游戏文件已装「合欢殿」 |
| 门派只收女弟子 | 把自己门派的男弟子比例设为 0 | 已自立门户 |
| 主角获得天赋「合欢宗主」 | 给主角（heroID 0）加天赋 393 | 游戏文件已装「合欢宗主天赋」；主角还没有 |

- 点「写入存档」。只写入改动的文件（Save / Hero），写前自动备份为 `Save.日期时间.bak`、`Hero.日期时间.bak`。
- 新旧两种存档格式都支持：游戏 1.1.3 起存档是 gzip 压缩的 JSON，修改器自动解压、修改后再按原格式压缩写回；旧版纯 JSON 存档照旧写纯 JSON。
- **游戏开着也可以写**，写完在游戏里重新读取这个存档即可。读档前别在游戏里存到同一槽位，否则修改会被覆盖。
- 如果存档在读取之后被改过（游戏存了档、或 Steam 云同步），会拒绝写入，重新点一下槽位再写。
- 合欢殿只能建在自己门派驻地（BuildingData 的「限制区域」设为 999 → 不会在新游戏里自动生成）。

---

## 3. 「合欢宗主天赋」页

自定义天赋 393「合欢宗主」的效果：

- 顶部两行：「当前设置」和「游戏里」实际装的效果，一致为绿色，不一致为橙色。
- 表格每行一个效果：
  - 「效果」下拉框：游戏效果表 SpeAddDataBase 里的全部 215 种效果，只列出其他行没用过的（不能重复）。
  - 「数值」：单位为 % 的填百分数（20 = +20%），其余填点数（5 = +5），负数为减少。
  - 「单位」「生效时机」（常驻/攻击时/被攻击时）「说明」自动显示。
- 「添加效果（n/24）」：最多 24 个（原版效果最多的天赋「终归一统」就是 24 个）。
- 「删除选中」「恢复默认」（吸内+20%、斗转+20%、内劲+20%、好感获取+20%）。
- 「保存并安装到游戏」：保存设置；如果天赋已安装，会自动更新游戏文件（需关游戏）；未安装则提示去「游戏文件」页勾选。
- 天赋名「合欢宗主」不能改（修改器靠名字识别自己的天赋）。
- 已拥有此天赋的角色无需改存档，下次进游戏即为新效果（存档只记天赋编号，效果读游戏文件）。
- 设置保存在 `%APPDATA%\LongYinMod\talent.txt`。

---

## 4. 命令行（排查用）

```
合欢宗修改器.exe --status  <游戏目录>
合欢宗修改器.exe --install <游戏目录> [hff] [custom] [book] [hhd] [tag]   （不写功能名 = 全部）
合欢宗修改器.exe --restore <游戏目录>
```
功能代号：`hff` 门派特性随特殊建筑，`custom` 自创武学，`book` 秘籍持有数量提示，`hhd` 合欢殿，`tag` 合欢宗主天赋。
注意 `--install` 是「设为这些功能」，没列出的已安装功能会被卸载。
