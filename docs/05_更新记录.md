# 更新记录

## 2026-11-15（首次研读：按最高经验的 90%）
- 首次研读改为当作已经研读过：研读记录直接写成同武学等级的最高研读经验，跳过得 90%（原版比例），不再打 8 折。同等级没有记录时仍用默认值 400 / 900 / 1500 / 2100 / 2600 / 3100 作为跳过实得。

## 2026-11-15（本门武学看藏经阁）
- 新功能（`lib`）：主角所在门派的人，秘籍在本门藏经阁里的武学算本门武学，吃本门武学威力加成（伤害和武学战力显示都改）；其他门派维持原判定。实现：新增代码节 `.hhlib`，改 `CountBaseDamage` 和 `GetSkillFightScore` 里的本门判定。
- 查明：灵塔殿「密宗修行」的加成是 修行等级 × 2% 的本门武学威力，只给主角；原判定下合欢宗没有本门武学，金刚密宗武学也不算。
- tools：新增 `libkf\`（汇编源码、模板生成脚本、模拟测试）。

## 2026-11-14（拍卖自动出价：快进时失效）
- 原来把 `skipping` 当成「主角放弃这一件」而不出价；查代码后确认「跳过」按钮只是快进（Update 里倒计时乘更大的系数、按钮变色），改为快进时照样自动出价。

## 2026-11-14（拍卖自动出价：修正开拍旁按钮）
- 开拍旁的「自动出价」被离开按钮挡住：改为放在离开按钮右边（离开按钮的子物体，跟开拍按钮同时显示 / 隐藏）。
- 点它没反应：开拍按钮的点击事件是游戏运行时加的，复制的按钮没有。改为点击时直接调用开拍，并打开这一件的自动出价。
- 两个复制按钮宽度 ×1.6、文字不换行（之前四个字会换行，只露出一部分）；认按钮时从被点的物体往上找 3 层父物体，文字往下找 3 层子物体。

## 2026-11-14（秘籍持有数量提示：武功也显示）
- 悬停武功时也显示（编撰界面里悬停的是武功，之前不显示）：挂 `QuickDetail.ShowSkillQuickDetail` 尾声，新代码有两个入口。
- 显示规则改为：背包 / 仓库 / 宗门仓库 / 藏经阁数量为 0 的行都不显示；全都没有时显示「背包：无」。
- 取主角改用自带初始化的静态 getter（AuctionController.Update 里同一个），避免在没看过秘籍提示前读到未初始化的类指针槽。
- tools：`bookcnt\test_emu.py` 改为测两个入口。

## 2026-11-14（拍卖自动出价）
- 新功能（`auct`）：拍卖大会「开拍」旁加「自动出价」按钮（开拍并对这一件自动出价），「出价」旁加「自动出价 / 停止自动」开关；开着时别人出价就按最低加价跟，下一口价超过背包钱数就停止。实现：新增可读写代码节 `.hhauct`，挂 `Button.Press`、`AuctionController.StartAuctionRoundButtonClicked`、`AuctionController.Update`，按钮在游戏里复制原按钮生成。
- 修改器 Core：元数据按命名空间找类（UnityEngine.Object）、解析字符串常量；新增节可指定属性。
- tools：新增 `autobid\`（汇编源码、模板生成脚本、模拟测试）。

## 2026-11-14（存档槽位标记）
- 游戏的槽位 0 是自动存档、槽位 10 是快速存档，游戏会自动覆盖。存档修改器（程序版 / 网页版）的存档列表和合欢宗修改器的存档页给这两个槽位加了「自动存档」「快速存档」标记。

## 2026-11-14（存档修改器：新旧存档格式对比后的修正）
- 对比旧格式（存档 8）和 1.1.3 新格式（存档 0），新版不再保存：人物派生数值、物品的价值 / 重量 / checkName / describe / isNew、武功的 equiped / belongHeroID / speEquipData / speUseData / *UseSpeAddValue / isNew，以及所有 null 字段。
- 物品「价值」：新存档改为只读（秘籍按游戏公式显示，其他显示「自动」），之前显示 0 且改了无效。
- 「秘籍稀有度拉满」：只改品阶；新存档不再写入游戏不读的价值字段。已确认旧存档用的价值公式与游戏 `ItemData.CountValueAndWeight` 一致。
- 武功「装备中」★：新存档按人物的装备记录（internal / dodge / unique / attackSkillSaveRecord，存的是武功列表下标）显示，之前新存档里一个都不显示。
- 生活技艺：提示潜力上限 100（游戏 `HeroData.GetMaxLivingSkill` 封顶）。

## 2026-11-14（首次研读跳过：按武学等级）
- 跳过经验改为按武学等级（KungFuData 等级 0~5）区分：取研读过的同等级武学的最高研读经验 × 80%；同等级没有记录时用默认值 400 / 900 / 1500 / 2100 / 2600 / 3100（按用户设定）。之前按秘籍品级取，而秘籍品级几乎都是同一级，结果所有武学跳过经验都一样。
