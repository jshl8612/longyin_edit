# 龙胤立志传 修改器项目

游戏：龙胤立志传（Unity 2020.3，IL2CPP）

本文件夹整理于 2026-11-13，对应游戏 2026-11 更新后的版本（存档版本 1.1.3，存档为 gzip 压缩 JSON）。

## 成品（release）

| 文件 | 用途 |
|---|---|
| `release\合欢宗修改器.exe` | Windows 程序：安装/卸载游戏文件补丁、改存档、设置合欢宗主天赋 |

可以放在任意位置使用。修改器第一次打开会自动找 Steam 里的游戏目录，找不到时手动「浏览…」。

网页版存档修改器（人物修改、城市/驻地地块扩建）由 `source\网页存档修改器` 构建，见 `docs\02`。

## 当前功能一览

合欢宗修改器（游戏文件，可逐项勾选安装/卸载）：
1. **门派特性随特殊建筑**：自己门派驻地里有哪个门派的特殊建筑，主角就拥有那个门派的门派特性——既能用该建筑里的门派功能按钮（如万剑、暗器），也会触发该门派特性的规则效果（如归宗、杀手、巧匠）。只对主角生效；其他门派、门派介绍文字、门派数值加成都不变。
2. **自创武学每品级 9 门**：原版每个品级只能自创 1 门。
3. **合欢殿**：新特殊建筑（编号 76，借用峨眉派「金顶」的外观、图标、内景），自立门户后可建造。
4. **合欢宗主天赋**：新天赋（编号 393），效果可在修改器里自定义（默认 吸内/斗转/内劲/好感获取 各 +20%）。

合欢宗修改器（存档）：解锁合欢殿、门派只收女弟子、给主角加合欢宗主天赋。

网页存档修改器：人物属性/天赋/武学等修改；城市与门派驻地的可建造地块扩建；拖入整个 Save 文件夹按槽位编辑。

## 重要提醒

- 游戏更新后 Steam 会用原版覆盖补丁：关闭游戏 → 打开修改器 →「检测」→「按勾选安装 / 更新」。用了合欢殿 / 合欢宗主天赋的存档，**装好补丁之前不要读档**。
- 改存档时如果开着 Steam 云存档，云端旧档可能在启动游戏时覆盖本地修改。
- 每次写入都会自动备份（游戏文件 `.bak`，存档 `文件名.日期时间.bak`）。
