# 龙胤立志传 修改器项目

游戏：龙胤立志传（Unity 2020.3，IL2CPP）

本文件夹整理于 2026-11-13，对应游戏 2026-11 更新后的版本（存档版本 1.1.3，存档为 gzip 压缩 JSON）。

## 成品（release）

| 文件 | 用途 |
|---|---|
| `release\合欢宗修改器.exe` | Windows 程序：安装/卸载游戏文件补丁、改存档、设置合欢宗主天赋 |
| `release\龙胤立志传存档修改器.exe` | 存档修改器（程序版）：放在游戏根目录双击运行，游戏数据从游戏文件读取，打开即显示存档列表 |
| `release\龙胤立志传存档修改器.html` | 存档修改器（网页版）：用 Edge 或 Chrome 打开，拖入 / 选择 Save 文件夹 |

合欢宗修改器和网页版可以放在任意位置使用；存档修改器程序版建议放在游戏根目录（不在游戏目录时会自动查找或让你选择）。修改器第一次打开会自动找 Steam 里的游戏目录，找不到时手动「浏览…」。

## 当前功能一览

合欢宗修改器（游戏文件，可逐项勾选安装/卸载）：
1. **门派特性随特殊建筑**：自己门派驻地里有哪个门派的特殊建筑，主角就拥有那个门派的门派特性——既能用该建筑里的门派功能按钮（如万剑、暗器），也会触发该门派特性的规则效果（如归宗、杀手、巧匠）。只对主角生效；其他门派、门派介绍文字、门派数值加成都不变。
2. **自创武学每品级 9 门**：原版每个品级只能自创 1 门。
3. **秘籍持有数量提示**：鼠标放在秘籍上时，在特效说明框下面多一个框，显示同一门武学秘籍在主角背包、个人仓库、所属门派的宗门仓库和藏经阁里的数量，按品质颜色分开（如「背包：1红1黄」）。背包一行总是显示（没有写「无」），其余几行没有就不显示。
4. **首次研读也可跳过**：原版只有研读过同一门武学同品级的秘籍，开始研读时才会问「是否跳过」（跳过得 最高研读经验 × 90%）。装上后，没研读过的也会问，跳过经验按**武学等级**定：取主角研读过的、武学等级相同的武学里最高研读经验的 80%；同等级一门都没研读过时用默认值（等级 0~5：400 / 900 / 1500 / 2100 / 2600 / 3100）。这个经验会记作这门武学该品级的研读记录。主角从没研读过任何秘籍时照旧进研读面板。
5. **合欢殿**：新特殊建筑（编号 76，借用峨眉派「金顶」的外观、图标、内景），自立门户后可建造。
6. **合欢宗主天赋**：新天赋（编号 393），效果可在修改器里自定义（默认 吸内/斗转/内劲/好感获取 各 +20%）。

合欢宗修改器（存档）：解锁合欢殿、门派只收女弟子、给主角加合欢宗主天赋。

网页存档修改器：人物属性/天赋/武学等修改；城市与门派驻地的可建造地块扩建；拖入整个 Save 文件夹按槽位编辑。

## 重要提醒

- 游戏更新后 Steam 会用原版覆盖补丁：关闭游戏 → 打开修改器 →「检测」→「按勾选安装 / 更新」。用了合欢殿 / 合欢宗主天赋的存档，**装好补丁之前不要读档**。
- 改存档时如果开着 Steam 云存档，云端旧档可能在启动游戏时覆盖本地修改。
- 每次写入都会自动备份（游戏文件 `.bak`，存档 `文件名.日期时间.bak`）。
